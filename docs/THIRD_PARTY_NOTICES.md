## Project-created runtime assets

All meshes, materials, icon art, interface graphics, sound effects, and music included in this source package were created specifically for DEADLANE: ZOMBIE BRIDGE in this implementation pass. The OBJ files and generated textures are deterministic original project assets and can be regenerated with the included authoring helpers `tools/generate_models.py`, `tools/generate_environment_models.py`, `tools/generate_surface_textures_v14.py`, and `tools/generate_graphics_v15.py`. No downloaded third-party models, textures, fonts, sound effects, or music are bundled.


The v1.5 graphics pass adds only project-created deterministic meshes and decals. No third-party runtime asset was added.
